# 🎬 React Movie – Film Arama Uygulaması

Merhaba!  
Bu proje, **React ile API bağlantısı kurmayı öğrenmek** amacıyla geliştirdiğim temel bir film arama uygulamasıdır.  
Dış bir film API'sine istek atarak, kullanıcıların aradıkları filmlerin bilgilerini listelemeyi hedefliyor.

React konusunda pratiğimi artırmak ve özellikle API'den veri çekmeyi, state yönetimini ve kullanıcıdan gelen input ile veri filtrelemeyi deneyimlemek amacıyla bu projeyi geliştirdim.

---

## 🔍 Ne Yapar?

- 🎥 Kullanıcıdan alınan arama terimiyle API'ye istek atar
- 📡 Gelen veriyi ekrana render eder (film adı, afiş, açıklama vs.)
- ⚠️ Geçersiz arama durumunda uyarı gösterir
- 🔄 Sayfa yenilenmeden arama yapılır (SPA mantığı)

---

## 🛠️ Kullanılan Teknolojiler

- ⚛️ **React** – Component tabanlı UI
- 🔄 **useState & useEffect** – React Hook'ları ile state ve lifecycle kontrolü
- 🌐 **Fetch API / Axios** – API'den veri alma
- 🖌️ **CSS** – Temel responsive stil

---

## 🧪 Öğrenilen Konular

- 🔌 API bağlantısı nasıl kurulur?
- 🧠 React içinde veri nasıl işlenir ve gösterilir?
- 💬 Inputlardan alınan veri ile nasıl dinamik arama yapılır?
- ⚠️ API hataları veya boş sonuçlar nasıl yönetilir?
